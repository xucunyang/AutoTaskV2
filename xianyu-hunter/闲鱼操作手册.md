# 闲鱼操作手册（xianyu-hunter 渠道 SOP）

> 依据全局规范第 13 条「外部渠道访问治理」：对第三方做程序化访问必须写清**节奏档位**与**预算**，
> 遇风控信号立即全停。本文件是闲鱼 App 自动化采集的**唯一操作事实源**。

## 一、渠道定义

| 项 | 值 |
|---|---|
| 渠道名 | `xianyu-idlefish` |
| 载体 | 闲鱼 App（`com.taobao.idlefish`），**GUI 自动化**，非 HTTP API |
| 账号 | `爱唱歌的虾片`（采集账号，非用户私人账号）|
| 设备 | 一加平板 `AUIFLJTKSGSWU4TK`（2000×2800）｜荣耀 `AADEGL4701000138`（720×1600）|
| 通道 | USB 序列号为主；无线 `192.168.31.208:5555` / `192.168.31.95:5555` 备援 |
| 单写者锁 | `xianyu-hunter/device-lease/devlease.py`（TTL 1800s，exit 2 = 被占，不硬抢）|
| 日预算 | **每设备 ≤ 48 轮/天**（半小时 1 轮）；单轮 ≤ 6 关键词 |

## 二、节奏档位（拟人化，禁止裸循环）

| 动作 | 间隔 | 理由 |
|---|---|---|
| 关键词切换 | **≥ 25s**（输词 ~8s + 结果加载 ~8s + 人工/脚本缓冲 ~9s）| 真人翻页节奏 |
| 同关键词重复搜 | **≥ 30 分钟**（= 轮次间隔）| 避免同词反复打 |
| 详情页 → 返回列表 | **≥ 4s** | 避免连点 |
| 同一 listing 收藏动作 | **只点一次**（重复点会 +1/+2 收藏数，污染数据）| 收藏数是证据 |
| 跨设备同词 | 允许（两台是不同账号会话/不同 IP 出口）| 双机并行 |

**禁止**：连续 3 次以上无间隔 tap、批量并发开 10+ listing、绕过滑块/验证码后重试。

## 三、风控信号 → 立即全停

出现以下任一，**立刻停止本渠道全部自动化**，写 `scan-log.md` 并报告用户，禁止重试轰炸/换 IP/换会话：

- 滑块验证 / 拼图 / 短信验证 / 扫码登录
- `访问频繁` / `操作过于频繁` / `请稍后再试` 弹窗
- HTTP 403 / 4030 / `is_ban`
- 账号被限制：搜索无结果、消息发不出、收藏不生效
- 连续 3 台 listing 打开后立即跳登录页

恢复条件：用户确认解除后再手动重启任务，不自动重试。

## 四、平台侧硬约束（会随版本变化，每次先验）

1. **webview 渲染** —— 搜索结果页/详情页的 `uiautomator dump` **不暴露价格与标题 text 节点**。
   → 必须走**视觉定位**（screencap → 读图 → 算坐标 → tap），不要试图 dump find_text（R27/R28/R29 连续三轮失败）。
2. **「内存容量」筛选器最高 32GB，无 64GB 选项** → 64G 机器无法用官方筛选过滤，只能关键词 + 视觉识别规格表。
3. **itemId 不暴露**（webview 渲染后链接里没有）→ 唯一可溯源路径 = **收藏 + 截图 + 卖家昵称**，三者缺一不进报告。
4. **收藏数是证据**：`<n>` 变黄 = 收藏成功；`✓ 收藏成功` toast = 二次确认。收藏数增减可作为"已收藏"的可验证痕迹。
5. **「行情」tab = 成交价基准**（R38 新发现，重要）：顶部 `全部｜AI智搜｜个人闲置｜**行情**｜用户`，行情内分 `在售好价｜**成交记录**`。
   - 可读「成交区间」+「发布价 → 成交价 + 发布天数」→ **判断好价的唯一硬基准**
   - **拼接词无数据**（`m1max64gstudio` 空），必须用正常词（`m1max 64g`）
   - 实测：`m1max64g满血` 成交区间 **¥9,800-10,665**（样本：发布价 12,222 → 24 天后成交 10,665）
6. **官方筛选 chip**（结果页第二行）：`个人闲置`｜`鱼小铺`｜`3期0息`｜`验货宝`｜`成色`｜`内存容量`｜`硬盘容量`｜`品牌`｜`屏幕尺寸`｜`拆修`
   - 点 `个人闲置` → 结果全是个人卖家（降噪最有效）
   - `验货宝` → 进一步降风险
   - `内存容量` **最高 32GB，无 64GB 选项**
7. **属性限定词 > 裸关键词**（R38 验证）：`m1max64g自用`、`m1max64g16寸1t32核` 命中率远高于 `m1max 64g`，且结果自带"个人卖家 + 满血配置"过滤。
   搜索建议里的现成高产词：`m1max64g16寸1t32核` / `m1max64g满血` / `m1max64gstudio` / `m1max64g4t` / `max64g1t16寸` / `m1max64g 银色` / `m1max64g14寸` / `m1max64g8t16寸`

## 六、中文输入（唯一正确姿势）

- 荣耀 / 平板**都必须**先 `ime set com.android.adbkeyboard/.AdbIME`，
  再 `am broadcast -a ADB_INPUT_TEXT --es msg '关键词'`。
- ASCII 词可 `input text "a%sb"`（`%s` = 空格）；**含中文一律 broadcast**，`input text` 会 NPE。
- 引号必须**外双内单**，否则远端 shell 拆参（msg 只收到第一个词）。
- **收尾必还原输入法**：平板 → `com.sohu.inputmethod.sogouoem/.SogouIME`；荣耀 → `com.baidu.input_hihonor/com.baidu.input_honor.ImeService`。

## 七、租约与收尾清单

- 取：`devlease.py acquire --device <串号> --session <唯一名> --ttl 1800 --task "..."`（exit 2 = 被占，跳过不抢）
- 还：`devlease.py release --device <串号> --session <唯一名>`
- 收尾三件套：①还原输入法 ②`rm -f /sdcard/s.png /sdcard/ui.xml /sdcard/d.xml` ③释放租约
- **K60 红米（`188182ec` / `23013RK75C`）是用户私人机，红线禁动**——仅在用户明确批准 + 取到租约 + 截屏确认不在用户手上时才可操作

## 八、失败回退阶梯

`裸 adb` → `android-agent`（Ghost MCP：`type_text`/`paste_text`/`get_elements`/`run_flow`）→ `ARTEMIS`（自主任务 + 留痕回放）

同一手段失败 **3 次必须换后端**，不许换参数重试。

## 九、已知故障与解法

| 故障 | 解法 |
|---|---|
| 设备 `device offline` | 荣耀：先 `ping PC` 唤醒 ARP 再 `adb connect`；平板：USB 兜底 `adb tcpip 5555` |
| 平板无线 .208 连不上 | 息屏/休眠或 tcpip 失效 → 需物理 USB + `adb tcpip 5555` |
| 荣耀在拨号盘/别的 App | 先 `am force-stop` + `am start` 闲鱼；**扫描脚本启动必须冷启动闲鱼** |
| 搜索框文字没进去 | 查 `ime list -s`，没切 ADBKeyboard 就先切 |
| dump 里找不到价格 | 正常现象，走视觉定位 |
| `input text` 中文 NPE | 改 broadcast |
| 脚本 ReadAllText 抛 FileNotFound | 已修：`ReadXmlSafe` + 优雅 abort（commit 618810b）|
