# t1_policy_scan 报告：中国现行房贷政策与市场证据（截至2026-09-30）

**数据截止说明**：目标日期 2026-09-30 已到达，本报告**实际数据截止日 = 2026-09-30**。其中：LPR 最新报价期为 2026-09-20；官方月度统计数据最新为 2026年8月（国家统计局 2026-09-15 发布）；居民杠杆率最新为 2026年二季度（NIFD 季报）；最新政策文件为 2026-09-29 发布的财金〔2026〕95号（自 2026-10-01 起实施，即"已发布、目标日期后生效"）。资料未覆盖处一律标注 [未覆盖]。

## 一、截至2026年9月30日，中国现行房贷政策（LPR、公积金利率、存量房贷调整、首付比例、各地购房补贴及房贷贴息）的具体内容、生效时间与适用口径是什么？

### 1.1 LPR：3.0% / 3.5%，已连续一年多未动
- **现行水平**：2026年9月20日报价，1年期 LPR **3.0%**、5年期以上 LPR **3.5%**，在该次报价有效期内适用，全国统一（s1、s2）。
- **生效时间**：5年期以上 LPR 自 2025-05-20 下调10BP至3.5%后，自2025年6月至2026年9月各期报价均为 3.5%，未再调整（s1）。
- **适用口径**：商业性个人住房贷款利率 = 最近一期同期限 LPR ± 加点；加点在合同期内固定，LPR 浮动，利率在定价周期内一年一变。1年期LPR 主要锚定5年期以内的短期贷款，市场流传的"2字头"房贷利率多属此类短期存量贷款，与市场普遍关注的5年期以上房贷利率不可混同（s14）。

### 1.2 公积金利率：首套2.6% / 二套3.075%，存量自2026-01-01自动下调
- **现行水平与生效时间**：依据中国人民银行《关于下调个人住房公积金贷款利率的通知》（2025-05-07发布），自 **2025-05-08** 起新发放贷款下调0.25个百分点——首套 5年以下（含）**2.1%**、5年以上 **2.6%**；二套 5年以下（含）**2.525%**、5年以上 **3.075%**（s8、s18、s19）。
- **存量调整生效时间**：**2026-01-01**，2025-05-08前已发放未结清的公积金个人住房贷款免申即享、系统自动下调（s7、s17、s19）；组合贷款仅公积金部分调整，商贷部分仍按 LPR 定价规则（s7）。
- **适用口径要点**：全国统一标准，但各地中心对"首套/二套"认定标准自行规定（如东莞要求家庭在本市无住房登记、全国范围未使用过公积金贷款等，s8）。**地方汇编口径不一致风险**：部分城市生活服务类汇编仍展示旧值（如"5年以上3.1%/3.575%"），应以央行通知与2025-05-08后各地公积金中心官方解读为准。
- **地方公积金制度优化**：2026年内厦门、四川、沈阳等地推进优化，沈阳将公积金贷款最低首付比例15%延续至2026年底、"商转公"比例上限由房价60%提高至80%；部分城市首套房贷款额度由120万元提高至156万元，使用场景扩展至首付、契税、物业费、装修款（s6）。

### 1.3 存量房贷调整：公积金已落地，商贷按可选重定价周期执行
- **公积金存量**：如上，2026-01-01 自动下调25BP（s7、s17、s19）。
- **商贷存量**：依据 2024-11-01 起落地的定价机制，借款人可随时申请将重定价周期调整为3个月、6个月或1年，重定价日在1月1日的客户于2026-01-01随LPR调整（s17）。上轮**全国性存量商贷批量调整**发生于2024年9—10月（市场利率定价自律机制倡议，统一调降LPR加点幅度，各银行2024-10-12前发细则）（s12）。
- **[未覆盖]** 未检索到2026年内发布的新一轮全国性存量商贷批量下调政策文件。

### 1.4 首付比例：全国下限统一不低于15%
- **政策与生效时间**：中国人民银行、国家金融监督管理总局《关于优化个人住房贷款最低首付款比例政策的通知》（2024年9月发布并实施，现行有效）：商业性个人住房贷款**不再区分首套、二套，最低首付款比例统一为不低于15%**；在此全国下限基础上，人民银行省级分行、金融监管总局派出机构按因城施策原则自主确定辖区各城下限（s12）。
- **背景口径**："517"政策后首套不低于15%、二套不低于25%曾是多数城市标配，后由上述通知统一为不低于15%（s13）。

### 1.5 各地购房补贴与房贷贴息：地方先行、中央于2026-10-01全国铺开
- **地方补贴/贴息（2026年内）**：全国已有**超20地**出台或优化住房贷款贴息政策（s5）。可核到的代表性口径：
  - 南京"宁六条"（2026-03）："卖旧买新"按贷款总金额**1%**贴息，全市贴息总资金限额1亿元（s5、s14）。
  - 广州（2026-05）：购新建商品住宅贷款总额≤300万元按**1%**补贴；≥300万元按每套最高**3万元**（s5）。
  - 上海"以旧换新"（2026-08）：外环外购新房且前后1年内售出本市二手房，按新建住房贷款总额**1%**补贴，单套最高**5万元**（s5）。
  - 泰州青年人才（2026-04）：公积金+商贷购首套新建商品住房，每年按贷款金额**2%**财政贴息（最高2万元/年），贴息期2年（s14）。
  - 芜湖：按揭购房者每年给予贷款利息**50%**补贴、每年上限1万元，补贴期限36个月，适用期为2025-07-01至2026-06-30（s14）。
- **中央贴息（新政，目标日期后生效）**：财政部、中国人民银行、金融监管总局《关于实施居民购房贷款贴息政策的通知》，**文号 财金〔2026〕95号**，2026-09-29发布，**自2026-10-01起实施，实施期限暂定1年**，全国范围内实施、不设试点城市名单。核心条款：
  - 支持对象须**同时满足**：① 使用新发放商业性个人住房贷款购买**首套住房**（不含用新发放商贷置换存量贷款）；② 所购住房建筑面积**≤120平方米**；③ 所购住房价格**≤150万元**。
  - 贴息标准：按贷款本金给予**年化1个百分点**、期限**不超过5年**的贴息；**单户可享贴息贷款规模上限100万元**。
  - 分担比例：中央财政90%、地方财政10%（省级及以下分担比例由省级财政部门确定）。
  - 经办银行：开展商业性个人住房贷款业务的银行均可办理。
  - 资金管理：采取"预拨＋结算"，建立"省对省"工作机制；财政部会同金融监管总局开展联合抽查，违规套取骗取的收回贴息资金（s3、s4）。

## 二、截至该时点，房价、成交量、居民杠杆率等市场数据表现如何，来源与统计口径是否一致？

### 2.1 房价：一线环比转涨，二三线降幅收窄，同比全面收窄
- **来源：国家统计局 2026年8月70城数据（2026-09-15发布）**（s15、s9）。
- 新建商品住宅：一线城市环比由上月持平**转为上涨0.1%**（上海+0.4%、广州+0.1%、深圳+0.2%，北京-0.2%）；二线环比-0.1%（降幅与上月相同）；三线环比-0.2%（降幅收窄0.1个百分点）。70城中新房环比上涨或持平21个，比上月减少2个。
- 二手住宅：一线环比+0.1%（涨幅回落0.1个百分点；上海+0.3%、深圳+0.1%、广州持平、北京-0.1%）；二线-0.3%；三线-0.3%。70城中二手环比上涨或持平8个。
- 同比：新房一线-0.9%（收窄0.2pct）、二线-2.7%、三线-4.1%（均收窄0.1pct）；二手一线-2.7%（收窄1.0pct，为年内最大收窄幅度）、二线-4.9%、三线-5.6%。
- **口径细节**：统计局指数为"上月=100 / 上年同月=100"的分面积段指数（s9）；第三方（中房研协）另给出"环比平均/同比平均"口径（8月新建住宅环比平均-0.17%、同比平均-3.29%），数值与统计局分线城市口径**不完全可比**（s15、s9）。

### 2.2 成交量：新房仍深度负增长，二手房网签正增长——两个口径方向相反
- **来源：国家统计局《2026年1—8月份全国房地产市场基本情况》（2026-09-15）**（s10）。
- 新建商品房：销售面积 **49880万㎡，同比-12.1%**（住宅-13.0%）；销售额 **47470亿元，同比-13.0%**（住宅-13.1%）。
- 二手房：**交易网签面积 54923万㎡，同比+10.6%**——**该指标来源为住房城乡建设部，与国家统计局新房口径不同源、不可直接相加或比较**（s10）。
- 库存与资金：8月末新建商品房待售面积75349万㎡（-1.1%）；1—8月房企到位资金50893亿元（-21.0%），其中**个人按揭贷款6846亿元（-22.4%）**，显示按揭需求端仍偏弱（s10）。

### 2.3 居民杠杆率：2026Q2 首次单季回落，居民部门持续去杠杆
- **来源：国家金融与发展实验室（NIFD）2026年二季度宏观杠杆率季报**（s11）。
- 宏观杠杆率 2026Q2 **下降1.1个百分点至308.2%**（Q1为309.3%）；居民部门 **由59.0%降至57.7%（-1.3pct）**；非金融企业179.5%（-0.5pct）；政府部门升至71.0%（+0.7pct）。
- 结构特征：居民部门"存贷双降"——Q2居民存款净减少0.11万亿元（近年首次转负），居民贷款净减少约0.7万亿元；报告指出居民信用收缩不能仅用房地产销售低迷解释，还叠加消费信贷需求不足、提前还贷与收入预期偏弱；并明确纠正"居民净资产回升=资产负债表已修复"的观点，认为当前属"降负债带来的被动增长"（s11）。

### 2.4 统计口径是否一致？——四处需注意的不一致
1. **新房 vs 二手房**：数据源不同（统计局 vs 住建部网签），1—8月增速方向相反（-12.1% vs +10.6%），不可直接比较（s10）。
2. **房价指数口径**：统计局70城分线城市指数（上月/上年同月=100）与第三方"平均涨跌幅"口径不同，数值有差异（s9、s15）。
3. **居民杠杆率口径**：NIFD 采用"总债务/名义GDP"的国家资产负债表口径（居民部门57.7%），与 BIS 等国际口径、与"住户贷款/名义GDP"简化口径均不可直接对齐（s11）。
4. **房贷利率口径**：央行/媒体披露的"新发放个人房贷加权平均利率3.1%"（2026年8月，s16）与各地个案报价（多数银行≥3%、个别外资行<2.8%）差异明显，个案报价含客户资质、合作渠道、贷款期限（部分为1年期LPR锚定的5年期以内贷款）等条件（s14、s16）。
5. **[未覆盖]** 居民杠杆率尚无2026年三季度数据（NIFD季报通常滞后一个季度），目标日期内最新仅为Q2。

## 三、在上述政策与市场证据下，房贷贴息政策的效果如何，未来市场走势可能如何？

需先明确：财金〔2026〕95号**自2026-10-01生效**，截至数据截止日（2026-09-30）**尚无一笔贴息贷款投放**，因此**实际执行效果数据在目标日期内不可得**（[未覆盖]）。以下为机构**事前测算与预期**，属预测而非已实现结果，引用时须区分。

### 3.1 效果测算：相当于对首套商贷"定向降息20—30BP"
- 广发证券宏观团队以"有关部门披露的100万元房贷累计少付近5万元"倒推：30年期商贷利率将从**3.1%左右降至2.8%—2.9%**，相当于**定向降息20—30BP**，与百城住宅租金收益率的差值缩减至35—45BP（s16）。
- 中泰证券：2026年8月全国新发放个人房贷加权平均利率3.1%，**贴息后前5年实际利率2.1%**；据中原地产数据，同期天津、成都二手房租金回报率为2.26%和1.94%——**贴息后房贷利率已接近部分城市租金回报率**（s16）。
- 机制意义（机构观点）：以财政"补息差"方式，**不触动贷款合同利率、不压缩银行净息差**，将财政资金定向投向真实自住需求，直接降低符合条件首套购房者实际资金成本约1个百分点（s5、s16）。

### 3.2 受益面：由"120㎡+150万元"两道门槛自动筛选，城市层级差异明显
- 政策全国统一、无试点名单，受益面由门槛自动筛选（s5）。机构测算口径差异较大：
  - 中金公司：超高能级城市约2%新房、14%二手房符合；高能级城市约25%新房、60%二手房符合；中低能级城市约50%新房、70%二手房符合（s16）。
  - 国金证券（85城样本）：符合条件小区占比约60.7%，对应成交套数占比63.4%、金额占比32.5%；一线/二线/三线/四线受益小区占比约15%/65%/75%（s16）。
  - 58安居客：核心受益层为中小三四线城市、县域及城市群卫星城（120㎡主流户型总价普遍40万—120万元）；普通二三线受益面较大；强二线仅外围板块局部受益（s5）。
  - 银河证券（措辞："精准导向三四线城市主力盘、二线远郊盘"）；中信证券宏观组预计"四季度地产销售将出现回暖，尤其是低线城市"（s16）。
- 对一线城市影响有限：京沪广深主流购房总价远超150万元，符合条件房源多为远郊极小户型，占比极低（s5）。

### 3.3 未来走势判断：边际改善可期，但难改结构性分化
- **偏乐观侧**：政策10月1日起实施恰对接"银十"窗口，稳定旺季预期；中短期可带动150万元总价段刚需盘去化边际改善、修复市场预期（s5）；机构判断贴息信号意义明显，对稳预期、促需求释放是直接利好（s5、s16）。
- **偏谨慎侧**：单一政策很难改变市场格局，**结构性分化主线延续**——核心城市、品质项目靠确定性取胜，远郊高库存区域仍以价换量（s5）。
- **约束条件**：贴息以1个百分点、单户上限100万元、期限最长5年为限，受财政资金有限性约束（s5）；政策暂定实施1年后是否延续，取决于执行情况与财政安排（s3、s5）。
- **市场基本面仍偏弱**：新房销售面积/金额1—8月双位数下滑、个人按揭贷款-22.4%、居民部门连续去杠杆且Q2房贷增速进一步回落，构成贴息效果的**对冲背景**（s10、s11）。
- **利率环境**：5年期以上LPR自2025-05-20以来维持3.5%未动（s1）；在"财政补息差"路径启动后，货币政策与财政政策的协同方式（s3提到"强化货币政策与财政政策协同联动"）将成为后续观察重点。[未覆盖] 截至数据截止日，未见2026年四季度LPR进一步下调的官方公告。

### 3.4 结论性判断（基于检索证据）
1. 现行房贷政策框架已形成"**低LPR基准 + 全国首付下限15% + 公积金首套2.6% + 存量公积金自动降息 + 地方补贴 + 中央财政贴息（2026-10-01起）**"的组合，政策方向为定向支持刚需自住（s1—s3、s6、s7、s12）。
2. 贴息属**需求端精准补贴**而非普惠降息，其效力高度依赖"120㎡/150万元"门槛与地方三四线房源结构，**对一线城市近乎无实质影响**（s5、s16）。
3. 市场层面已出现**边际企稳信号**（一线房价环比转涨、同比降幅全面收窄、二手房网签正增长），但**量的层面（新房销售、按揭投放）仍深度负增长、居民继续去杠杆**，止跌回稳仍需政策合力与收入预期改善（s10、s11、s15）。
4. 2026年四季度至2027年的关键观察点：贴息实际申领与信贷投放数据（[未覆盖]，目标日期内不可得）、贴息政策是否续期、LPR是否进一步下调、房价同比能否转正。
