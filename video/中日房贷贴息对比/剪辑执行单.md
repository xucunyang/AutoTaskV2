## 一、先做这三件事

1. **导出 SVG → PNG**：剪映不能直接吃 SVG。用浏览器打开
   `charts/s1_policy.svg` 等，右键另存为 PNG（1080×1350，4:5），
   或用 Inkscape / `rsvg-convert` 批量转。
   - 批量：`for f in charts/*.svg; do rsvg-convert -w 1080 "$f" "${f%.svg}.png"; done`
2. **补空镜**：图表之外只需要 4 段实拍——日本东京街景、日本地方空街、
   中国上海夜景、三四线空房。按 `素材需求单.md` 去 Pexels/Pixabay 找
   免费可商用的，其余全是自制卡片。
3. **录口播**：照文稿念，注意第 8/10 镜的停顿。

## 三、字幕与合规（重要）

口播里**不能念**的数字：

| 数字 | 原因 |
|---|---|
| 日本新开工逐年数值 | 报告只给到"峰值→80-90万户"区间，没有逐年来源。`s4_newstarts.svg` 的逐年曲线是**动画示意** |
| 日本利率曲线具体百分比 | 概念图，无逐年来源。只念"利率越低越有效，2023 起抬头" |

可以念的数字（均有出处）：`0.7%`、`80–90 万户`、`13–14%`、`900 万套`、
`120㎡`、`150万`、`1 个百分点`、`5 年`、`100万`、`3.1%`、`2.1%`、
`-1.03 万亿`、`188 亿`、`-12.1%`、`+10.6%`、`-21%`、`省 5 万`。

措辞上避免"必跌/必涨"，改用"方向性判断""可证伪观测点"。
字幕建议固定加：`数据来源：公开政策文件与统计`。

## 五、素材复现

图表是脚本生成的，改数据后重新生成并校验：

```bash
cd video/中日房贷贴息对比
python scripts/make_charts.py     # 生成全部 SVG
python scripts/check_charts.py    # 校验结构 + 数据一致性 + 量纲
```

两条命令都由 `orchestrator/tests/test_video_assets.py` 覆盖，
跑 `pytest tests/test_video_assets.py` 即可确认素材没有漂移或标错量纲。
